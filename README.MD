## POS BACKEND

## 📖 Resumen
Este proyecto es un backend escrito en **Go** utilizando el framework **Fiber**.
Actualmente se encuentra en una fase inicial, con configuracion básica y documentacion alineada al desarrollo incremental.

## 📌 Versionado
El proyecto sigue la convención **SemVer (vX.Y.Z)**.
