# Guía — Kárdex de inventario

## 1. Propósito

Explica cómo consultar el kárdex: el historial de movimientos de un
artículo en una bodega (entradas, bajas, traslados, despachos y saldo
inicial) con su saldo después de cada movimiento. Úsalo para preguntas
como "¿cómo genero el kardex?", "¿dónde veo el historial de un producto?".

## 2. Cómo llegar

La pantalla del Kárdex se abre desde el inicio:

1. Presiona **"Seleccionar módulo"** en la barra superior.
2. Elige el módulo **Inicio**.
3. En **Accesos rápidos**, presiona la tarjeta **Inventario**.
4. Presiona la tarjeta **Kardex**.

## 3. Cómo generar el kárdex

1. En **Artículo**, escribe el código o el nombre y selecciónalo.
2. Elige la **Bodega**.
3. Si quieres, elige un **Lote** (es opcional).
4. Indica la **Fecha inicio** y la **Fecha fin**.
5. Presiona **Generar Kardex**.
6. Si lo necesitas en archivo, presiona **Excel** para descargarlo.

## 4. Cómo leer el resultado

Cada fila muestra **Fecha**, **Tipo de movimiento**, **Documento**,
**Referencia**, **Entrada**, **Salida**, **Saldo**, **Costo / Unidad** y
**Estado**. El **Saldo** es la cantidad que quedó después de ese
movimiento.

## 5. Ejemplos

Pregunta: ¿cómo genero el kardex de la Pepsi de este mes?
Respuesta esperada: los pasos de "Cómo llegar" y "Cómo generar el
kárdex", con la primera y la última fecha del mes.
